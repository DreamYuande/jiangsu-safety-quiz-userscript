# 江苏省大学生安全知识竞赛题库助手

适用于江苏省第十五届大学生安全知识竞赛网页的油猴脚本。当前版本：**1.5.0**。

## 功能

- 内置 1000 道安全知识竞赛题目，按题干和选项文字精确匹配。
- 同时适配电脑版 `/deimos/` 和手机版 `/phobos/` 页面。
- 支持单选题、多选题和判断题；填写后核对选中状态再翻题。
- 支持开始、暂停、继续；未匹配、答案冲突或出现网页弹窗时暂停。
- 可设置 0～100% 目标正确率。按本轮从当前题至最后一题的题数安排对错，四舍五入到整题；低于 100% 时会故意填写部分错误答案。修改比例会重建剩余题目的计划，已答题不计入新计划。实际得分以网站判分为准。
- 白色圆角浮窗，可用鼠标或触摸拖动；支持收起和展开。
- 电脑端宽 340px；小屏幕宽 224px，收起后宽 156px。
- 脚本不点击交卷按钮。网站倒计时结束时的自动交卷仍由网站控制。

## 安装

1. 在支持用户脚本的浏览器中安装 Tampermonkey（油猴）或兼容的脚本管理器。
2. 点击 [安装／下载脚本](https://raw.githubusercontent.com/DreamYuande/jiangsu-safety-quiz-userscript/main/%E5%AE%89%E5%85%A8%E7%9F%A5%E8%AF%86%E7%AB%9E%E8%B5%9B%E9%A2%98%E5%BA%93%E5%8A%A9%E6%89%8B.user.js)，在脚本管理器弹出的页面中确认安装。
3. 停用同一助手的旧版，刷新竞赛答题网页。
4. 如需设置正确率，输入百分比后点“应用”，再点“开始作答”。

手机需要使用支持用户脚本的浏览器；电脑版和手机版使用同一个文件。按住浮窗标题栏可拖动，“收起”可减少遮挡。

## 适用页面

- `https://mars.mycourse.cn/deimos/*`
- `https://mars.mycourse.cn/phobos/*`

脚本只匹配以上站点路径。题库对应第十五届竞赛，页面结构或题库变化后需要重新核对适配情况。

## 数据说明

内置江苏省第十五届大学生安全知识竞赛题库，共 1000 题，包含题干、选项和答案，无需另外导入题库。

脚本不包含用户的学号、账户凭据或专属活动链接，也没有新增向外部服务器上传题库或答案的逻辑；通过竞赛网页点击选项时，答案仍由网页按其自身逻辑保存。

## 验证情况

电脑和手机版的早期通用答题版本已有实测运行记录。1.5.0 的语法、题库答案格式、两端答题与正确率逻辑、鼠标与触摸拖动逻辑通过本地模拟检查。手机版三种题型的页面结构曾现场核对；用户已完成 1.5.0 的手机实机外观和完整 100 题流程验证。
